# DsuLoader：安装计划与完整性检查

这是原交接计划 P1 的首个实现批次，基于 PR #3 和卡片身份保护 PR #4；不替换 Android 的 gsid，不自动修改 AVB、vbmeta 或 SELinux。

已接入实际安装入口：

- `InstallPlanner` 在准备流程开始时生成不可变的 `InstallPlan`，固定来源、容量、格式、后端和权限环境。自动模式沿用现有设置；明确选择 root 直连时，不满足条件就失败，不会静默换后端。
- root 直连限定 root + Android 11 以上。Shizuku/system 模式仍委托系统 DSU 应用；ADB 模式仍生成需要用户执行的命令。
- 每次提交/重试前核对权限环境。容量转换检查范围及溢出，错误进入现有单一终态和工作目录清理路径。
- 可选的 SHA-256 指的是**所选原始文件**，例如 `.gz` 的压缩文件字节。先将它流式复制到当前任务的工作目录并计算校验值，匹配后只处理这份副本；校验不匹配、写入失败或取消都停止准备。缓冲区为 256 KiB。校验不代表镜像来自可信发布者。
- `.img/.gz/.gzip/.xz/.zip` 后缀大小写均可。ZIP 仍受原有分区白名单、重复项与路径校验约束；并不接受任意 OTA 包。
- 中间文件清理显式保留准备结果，修复准备好的 ZIP 或 `.gzip` 副本被清理掉的问题。失败/取消的最终清理仍删除全部任务文件。

默认不计算 SHA-256；没有填写预期值时，沿用已有格式校验。gzip 自动尺寸依旧通过完整解压计数计算；手工覆盖尺寸的既有限制仍存在。

验证：`python3 tools/wiring-probes/run_wiring_probes.py . --deps <目录>` 同时运行项目纯 JVM 测试和抽取生产方法的接线 probe。它不覆盖 Android ViewModel 生命周期、真实 SAF 或 Binder。

后续阶段尚未实现：独立于 ViewModel 的长任务服务、任务持久化及重开核对、下载与断点恢复、带签名的自有包格式、多槽位。不得据此宣称后台进程死亡后可以继续写分区。

设备验收仍需检查：真实权限变化、SAF 工作目录的复制/清理/系统可读性、大文件校验时间与空间占用、系统 DSU 交接、root 取消清理及重启。当前云环境缺少 KVM，按用户要求停止模拟器尝试。
